# llambda-agent

VS Code extension that opens the llambda command line against an NVIDIA model.

Each user supplies their own NVIDIA API key. Run **llambda-agent: Set NVIDIA API Key**. The key is stored in VS Code secret storage and is not included in this extension. The base URL and model are the `llambda-agent.baseUrl` and `llambda-agent.model` settings.

Commands:

- **llambda-agent: Open Command Line**
- **llambda-agent: NVIDIA**
